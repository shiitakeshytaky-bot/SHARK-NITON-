# Dr. Fatma | Wellness & Rehabilitation — Website

موقع Premium 3D لمركز تغذية وعلاج طبيعي (د. فاطمة — مدينة العبور).
موقع static بالكامل (HTML / CSS / JavaScript) — **مش محتاج build ولا Node**، وبيشتغل مباشرة على GitHub Pages.

## الملفات

| الملف | وظيفته |
|---|---|
| `index.html` | هيكل الصفحة وكل الأقسام (النصوص الإنجليزية) |
| `style.css` | التصميم والألوان والـ responsive ودعم العربي RTL |
| `main.js` | المجسمات 3D والحركات والفورمز والترجمة العربية وزر اللغة |
| `config.js` | القيم الافتراضية (لو `content.json` مش موجود أو الخانة فاضية) |
| `content.json` | **محتوى الموقع اللي بتعدّليه من الداشبورد** (تواصل، عن الدكتورة، خدمات، آراء، رابط الشيت) |
| `admin.html` `admin.css` `admin.js` | **لوحة التحكم** |
| `booking-backend.gs` | كود Google Apps Script اللي بيسجّل الحجوزات وطلبات التوظيف في Google Sheet |
| `dr-fatma.jpg` | صورة الدكتورة |
| `workshop-nutrition.jpg` | بوستر الورشة |

## لوحة التحكم

الرابط: `https://USERNAME.github.io/اسم-الـrepo/admin.html`

من اللوحة تقدري تعدّلي: **بيانات التواصل** (واتساب، تليفون، مواعيد، خريطة، سوشيال) — **عن الدكتورة** (الصورة والنصوص) — **الخدمات** (إضافة/تعديل/حذف/ترتيب) — **آراء العملاء** — وتشوفي **الحجوزات** و**طلبات التوظيف**.

بعد أي تعديل اضغطي **حفظ ونشر**، والموقع بيتحدّث خلال دقيقة أو اتنين.

### إزاي تدخلي اللوحة (مرة واحدة)

اللوحة بتحفظ على GitHub بنفسك، فمحتاجة **توكن** (Token):

1. GitHub ← صورتك ← **Settings** ← **Developer settings** ← **Personal access tokens** ← **Fine-grained tokens**.
2. **Generate new token**، اكتبي أي اسم.
3. **Repository access** ← **Only select repositories** ← اختاري الـ repo بتاع الموقع.
4. **Permissions** ← **Repository permissions** ← **Contents** ← **Read and write**.
5. **Generate token** وانسخيه (بيظهر مرة واحدة).
6. افتحي `admin.html`، الصقي التوكن، وعلّمي "تذكّرني" لو الجهاز بتاعك.

⚠️ التوكن بيدّي صلاحية على الموقع. ماتشاركيهوش مع حد، ولو ضاع امسحيه من GitHub واعملي واحد جديد. صفحة `admin.html` ظاهرة لأي حد يعرف رابطها لكنها **ما بتشتغلش من غير التوكن**.

## ربط Google Sheet (الحجوزات وطلبات التوظيف)

الحجز بيروح واتساب **وكمان** بيتسجّل في Google Sheet، فمايضيعش لو العميل ماضغطش "إرسال" في واتساب.

1. ادخلي على <https://sheets.new> وسمّي الملف (مثلاً: حجوزات د. فاطمة).
2. من القائمة: **Extensions** ← **Apps Script**.
3. امسحي الكود الموجود، وانسخي محتوى ملف `booking-backend.gs` كله والصقيه، واضغطي **Save**.
4. من الترس (**Project Settings**) ← **Script properties** ← **Add script property**:
   الاسم `ADMIN_KEY` والقيمة كلمة سر طويلة من عندك (احتفظي بيها).
5. **Deploy** ← **New deployment** ← النوع **Web app**:
   - **Execute as:** Me
   - **Who has access:** Anyone
   ثم **Deploy** ووافقي على الصلاحيات (لو ظهر تحذير: **Advanced** ← **Go to project** ← **Allow**).
6. انسخي رابط **Web app URL** (بينتهي بـ `/exec`).
7. افتحي اللوحة ← تبويب **الحجوزات**: الصقي الرابط وكلمة السر ← **حفظ ونشر**.

بعدها أي حجز أو طلب توظيف جديد بيظهر في الشيت (ورقتين: `Bookings` و`Applications`) وفي اللوحة، وتقدري تغيّري حالته (جديد، تم التواصل، تم، ملغي) أو تحذفيه.

ملاحظات:
- لو عدّلتي كود الـ `.gs` بعد كده لازم **Deploy ← Manage deployments ← Edit ← New version**.
- الرابط ممكن حد يبعت عليه حجوزات وهمية، لكن **القراءة والحذف مش ممكنين من غير ADMIN_KEY**، والموقع فيه فخ للبوتات (حقل مخفي).
- بيانات العملاء بتتخزن في حساب Google بتاعك، فحافظي على أمان الحساب ومتشاركيش الشيت.

## زر اللغة (عربي / English)

- الزر في أعلى الصفحة، والموقع بيفتكر اختيار الزائر. اللغة الافتراضية من `defaultLang` في `config.js`.
- النصوص الإنجليزية في `index.html`، وترجمتها العربية في `main.js` (الكائن `AR`). وصف الخدمات من اللوحة.

## قبل ما تنشر / ملاحظات

- المؤهلات وسنين الخبرة والنبذة والشهادات: لحد ما تكتبيها من اللوحة بتظهر كنص مؤقت `[ ... ]`. اكتبي بيانات حقيقية بس.
- آراء العملاء: خدي موافقة صاحب الرأي، وماتنشريش نتائج علاجية أو وعود.
- لو غيّرتي حاجة من اللوحة وبعدين غيّرتيها في `config.js`، **اللوحة بتتغلّب** لأن `content.json` هو اللي بيتقرأ الأول.

## الرفع على GitHub Pages

1. **New repository** (Public) ← **Add file → Upload files** وارفعي كل الملفات في الصفحة الرئيسية (مش جوه فولدر) ← **Commit changes**.
2. **Settings → Pages**: **Branch: main** و**Folder: / (root)** ← **Save**.
3. بعد دقيقة: `https://USERNAME.github.io/اسم-الـrepo/`
