# Dr. Fatma | Wellness & Rehabilitation — Website

موقع Premium 3D لمركز تغذية وعلاج طبيعي (د. فاطمة — مدينة العبور).
موقع static بالكامل (HTML / CSS / JavaScript) — **مش محتاج build ولا Node**، وبيشتغل مباشرة على GitHub Pages.

## الملفات (6 ملفات — كلها في الصفحة الرئيسية للـ repo)

| الملف | وظيفته |
|---|---|
| `index.html` | هيكل الصفحة وكل الأقسام (النصوص الإنجليزية) |
| `style.css` | التصميم والألوان والـ responsive ودعم العربي RTL |
| `main.js` | المجسمات 3D والحركات والفورم والترجمة العربية وزر اللغة |
| `config.js` | **الإعدادات** (اللغة الافتراضية، الواتساب، التليفون، المواعيد، الخريطة، السوشيال، آراء العملاء) |
| `dr-fatma.jpg` | صورة الدكتورة في قسم "عن الدكتورة" |
| `README.md` | الشرح ده |

## زر اللغة (عربي / English)

- الزر في أعلى الصفحة. الموقع بيفتكر اختيار الزائر.
- اللغة الافتراضية عند أول زيارة بتتحدد من `defaultLang` في `config.js` (`"ar"` أو `"en"`).
- كل النصوص الإنجليزية في `index.html`، وترجمتها العربية داخل `main.js` في الكائن `AR` (ووصف الخدمات في مصفوفتي `nutrition` و`physio`).

## آراء العملاء

- افتح `config.js` وضيف الآراء الحقيقية في `testimonials` (فيه مثال جاهز بالتعليق).
- طول ما القائمة فاضية بتظهر آراء تجريبية مكتوب عليها "محتوى تجريبي"، وبتختفي أول ما تضيف رأي حقيقي.
- ⚠️ خدي موافقة المريض/ة قبل نشر رأيهم أو اسمهم، وماتنشريش نتائج علاجية أو وعود.
- زر "شاركنا تجربتك عبر واتساب" بيخلّي العميل يبعتلك رأيه على الواتساب، وإنتِ تضيفيه بعد موافقته.

## الصورة

- الصورة موجودة باسم `dr-fatma.jpg`. لو عايزة تغيّريها، استبدلي الملف بصورة جديدة بنفس الاسم (يفضّل صورة عمودية 4:5، حوالي 800×1000 بكسل).

## قبل ما تنشر — مهم ⚠️

1. في `config.js` غيّري `whatsapp` للرقم الحقيقي بالصيغة الدولية بدون `+` (مثال: `201012345678`)، وكمان `phoneDisplay` و`hours`.
2. (اختياري) ضيفي رابط Google Maps Embed في `mapEmbedUrl`، وروابط السوشيال.
3. في `index.html` استبدلي بيانات `[ ... ]` (المؤهلات، سنين الخبرة، الشهادات، السيرة) ببيانات حقيقية، وفي `main.js` ترجمتها العربية (`a_q_v` و`a_e_v` و`a_bio_p` و`a_cert_p`).

## الرفع على GitHub Pages

1. اعملي **New repository** (مثلًا `dr-fatma-website`)، خليه Public.
2. **Add file → Upload files** وارفعي الملفات الستة في الصفحة الرئيسية (مش جوه فولدر).
3. **Commit changes**.
4. **Settings → Pages**: اختاري **Branch: main** و**Folder: / (root)** ثم **Save**.
5. بعد دقيقة هيظهر الرابط: `https://USERNAME.github.io/dr-fatma-website/`

لو بتحدّثي موقع مرفوع قبل كده: ارفعي الملفات الجديدة بنفس الأسماء وهتستبدل القديمة (Commit changes).

## ملاحظات تقنية

- مكتبات Three.js وGSAP بتتحمل من CDN، فالموقع محتاج إنترنت وقت التشغيل.
- لو الجهاز مش بيدعم WebGL أو الـ CDN اتحجب، الموقع بيفضل شغال بخلفية بديلة.
- الحركات بتتقلل تلقائيًا لو المستخدم مفعّل "Reduce motion".
- فورم الحجز بيفتح واتساب برسالة جاهزة فيها الاسم والرقم والخدمة (مفيش سيرفر).
