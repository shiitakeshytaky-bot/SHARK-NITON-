لوحة تحكم الموقع

ادخلي بالتوكن الخاص بيكِ. التوكن بيتحفظ على جهازك بس.

إزاي أعمل التوكن؟
  1. ادخلي على GitHub ← صورتك فوق ← Settings.
  2. من القائمة الشمال في الآخر: Developer settings ← Personal access tokens ← Fine-grained tokens.
  3. اضغطي Generate new token واكتبي أي اسم (مثلاً: dashboard).
  4. Repository access ← Only select repositories ← اختاري الـ repo بتاع الموقع.
  5. Permissions ← Repository permissions ← Contents ← اختاري Read and write.
  6. اضغطي Generate token وانسخي التوكن (بيظهر مرة واحدة بس) والصقيه هنا.

التوكن ده بيدّي صلاحية على الموقع بس. ماتبعتيهوش لأي حد، ولو ضاع امسحيه من GitHub واعملي واحد جديد.
